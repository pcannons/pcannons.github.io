# Sophia Calendar Sync

A personal desktop utility that keeps a dedicated Google Calendar up to date from selected Apple calendars and a shared academic deadline spreadsheet.

The utility runs locally on its owner's Mac. It reads configured source calendars, spreadsheet rows and syllabus metadata, then updates its own mirrored events in an existing Google Calendar. It preserves existing event IDs, avoids duplicate imports, and flags ambiguous changes for review.

This is a personal-use application, not a public sign-up service. This website contains documentation only and does not collect calendar data or credentials.
